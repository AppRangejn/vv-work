# VV Work — Платформа з пошуку роботи та працівників у Європі

* **Демо(Vercel):** [https://vv-work-lake.vercel.app](https://vv-work-lake.vercel.app)
* **Репозиторій:** [https://github.com/AppRangejn/vv-work](https://github.com/AppRangejn/vv-work)

---

## Стек технологій

* **Фронтенд:** React 19, TypeScript (Strict Mode)
* **Збірка:** Vite
* **Стилі:** Tailwind CSS
* **Роутинг:** React Router
* **Тести:** Vitest + React Testing Library (100% покриття)

---

## Встановлення та запуск

```bash
# Клонування репозиторію
git clone [https://github.com/AppRangejn/vv-work.git](https://github.com/AppRangejn/vv-work.git)
cd vv-work

# Встановлення залежностей
npm install

# Запуск локального сервера розробки
npm run dev

# Прогін unit тестів
npm run test:coverage

# Продакшн білд та перевірка типів TypeScript
npm run build

# Перегляд продакшн білду локально
npm run preview
```


## Мої рішення

1. **Власна локалізація без сторонніх бібліотек (`LanguageContext`)**
   Замість додавання громіздких бібліотек типу `i18n` створив типізований контекст на чистому React (`LanguageContext`). Він керує перемиканням мов (UA / EN), зберігає словник перекладів для статичних текстів, категорій, інлайн-помилок валідації. 
   У брифі цієї вимоги не було, але оскільки це платформа для працевлаштування в Європі, сервіс орієнтований не лише на українських пошукачів, а й на європейських роботодавців.

2. **Виправлення поведінки скролу при переходах (`ScrollToTop`)**
   Додав компонент `ScrollToTop`, який слухає `pathname` через `useLocation` і повертає користувача на початок сторінки, покращуючи UX навігації.

3. **Стейт-менеджмент через URL замість Redux/Zustand**
   Для фільтрації та пошуку вакансій використав параметри запиту (`URLSearchParams`). Це робить стан синхронізованим із браузером: користувач може зберегти сторінку з обраними фільтрами в закладки або поділитися прямим посиланням, і результати пошуку не зникнуть.

4. **Оптимізація ре-рендерів та пошуку (Debounce + useMemo)**
   Написав власний хук `useDebounce` із cooldown 350мс, щоб усунути зайві запити та перемальовування списку при кожному натисканні клавіші. Фільтрацію загорнув у `useMemo`, що гарантує обчислення результатів лише при зміні вихідних параметрів.

5. **Окремі сценарії заявки для кандидата та роботодавця**
   На сторінці контактів і в модалках розділив форму на два режими (шукач роботи vs роботодавець). Для кожного передбачено власні плейсхолдери, валідацію контакту (телефон або Telegram-`@username`) та оптимістичний UI сабміту з інлайн-помилками.
